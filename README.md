# Docentes del Edificio 2 - UT Coahuila

Aplicación en Python para manipular los datos de los docentes del edificio 2 de la Universidad Tecnológica de Coahuila: número de empleado, nombre y especialidad.

## Funciones
- Agregar, buscar, actualizar y eliminar docentes
- Validación de datos (campos obligatorios y número de empleado único)
- Presentación de datos en tabla, CSV y JSON

## Cómo ejecutarlo
```
python main.py
```
Genera los archivos `datos/docentes.csv` y `datos/docentes.json`.

## Cómo correr las pruebas unitarias
```
python -m unittest -v
```
